#Casas Rurales – Next.js

##Funcionalidades

- Listado de casas rurales con imágenes e información básica.

- Búsqueda por nombre o ubicación.

- Página de detalle de cada alojamiento con características, opiniones y botón de reserva.

- Diseño responsive.

- Optimización de imágenes mediante next/image.

- Estrategias de renderizado

- Se han utilizado dos estrategias de renderizado:

ISR (Incremental Static Regeneration): para el listado de casas rurales, con una revalidación de 60 segundos.

SSR (Server-Side Rendering): para las páginas de detalle.
